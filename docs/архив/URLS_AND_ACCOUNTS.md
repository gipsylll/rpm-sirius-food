## 👥 Тестовые аккаунты

Все пароли в системе по умолчанию: `student123`, `cook123`, `courier123`, `admin123`.

| Роль | Email | Пароль | Для чего использовать при показе |
| :--- | :--- | :--- | :--- |
| **Студент** | `student@sirius.ru` | `student123` | Просмотр меню, создание заказов, отмена **своего** заказа, пополнение баланса |
| **Второй студент** | `other_student@sirius.ru` | `student123` | **Проверка IDOR**: попытка отменить заказ первого студента (получаем `403 Forbidden`) |
| **Повар** | `cook@sirius.ru` | `cook123` | Просмотр кухни (`/orders/kitchen`), создание блюд, назначение курьера |
| **Курьер** | `courier@sirius.ru` | `courier123` | Просмотр своих доставок (`/delivery/my`), завершение доставки |
| **Администратор** | `admin@sirius.ru` | `admin123` | Полный неограниченный доступ ко всем эндпоинтам |

## 🔐 Как быстро авторизоваться в Swagger UI

1. Откройте [http://localhost:8000/docs](http://localhost:8000/docs).
2. Раскройте эндпоинт **`POST /auth/login`**, нажмите **Try it out**.
3. Введите нужный email (например, `student@sirius.ru`) и пароль (`student123`), нажмите **Execute**.
4. В блоке ответа (Response body) скопируйте значение поля `"access_token"` (без кавычек).
5. Прокрутите страницу в самый верх и нажмите зелёную кнопку **Authorize** 🔓 справа.
6. Вставьте скопированный токен в поле **Value** и нажмите **Authorize** → **Close**.
7. Теперь все защищённые эндпоинты будут выполняться от имени этого пользователя!
